# Прототип квартиры
Согласованный срез: независимый JSON, Python CLI валидации и калибровки, Three.js viewer с ручным JSON-редактором. Автораспознавание изображений и качественная мебель — следующие этапы.
Координаты плана [x,y] отображаются в Three.js как [x,height,y]. Геометрия либо в метрах с известным источником масштаба, либо в пикселях с неизвестным масштабом; во втором случае метрический просмотр запрещён. Высоты и толщины также принадлежат системе единиц документа. Стены — прямые отрезки; проёмы привязаны смещением от начала стены. Комнаты — простые полигоны без отверстий. Модели мебели адресуются modelId и размещаются экземплярами, библиотека не зависит от квартиры.
Ошибка JSON не заменяет последнюю рабочую сцену. Коррекция сохраняется экспортом файла. Прогулка — свободная навигация без физики; это явно указано в интерфейсе.
