# Кандидаты стен из растрового плана

Согласованный следующий срез: `recognize plan.jpg`, автоматическое выделение стен в пикселях, JSON кандидатов и диагностическое наложение. Координаты под исходник не прописываются. Масштаб plan.jpg неизвестен.

Отдельный контракт `schema/wall-candidates.schema.json` не подменяет контракт готовой квартиры: нет выдуманных комнат, высот, дверей или окон. Исходник сохраняется; вывод записывается только в новый каталог.

Базовый алгоритм: порог Otsu, удаление тонких штрихов, направленное морфологическое открытие, группировка соседних строк/столбцов в отрезки и объединение близких коллинеарных кандидатов без закрытия широких разрывов. Параметры зависят от размера изображения. Это эвристический поиск горизонтальных и вертикальных стен; результат требует проверки по наложению. Диагонали, тонкие стены и отделение толстых предметов мебели пока не поддерживаются.

Тесты: синтетические стены с известными координатами, тонкая мебель, дверной разрыв, изменение разрешения, пустой/нечитаемый файл, защита исходника и существующего вывода. Реальный план проверяется визуально и по схеме, без заявления об измеренной точности.
