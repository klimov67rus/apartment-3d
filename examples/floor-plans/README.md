# Примеры планировок

Положите сюда исходные изображения планов квартир: JPG или PNG. Желательны изображения хорошего качества, без перспективных искажений. Разметка не нужна.

Если известны размеры или площади, можно добавить рядом текстовый файл с тем же именем, например `plan-01.txt` для `plan-01.jpg`. Указывайте, к какой стене или помещению относится размер. Неизвестные размеры оставляйте без предположений.
